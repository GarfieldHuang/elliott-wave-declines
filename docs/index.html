波浪下跌段圖鑑

把台股、費半、那斯達克 100、標普 500 自 2000 年以來每一段主要下跌，用同一套規則數浪、量費波南希比率， 再回測一件事：跌到一半的時候，用當下的資料推算低點，到底準不準？

波浪標記 即時推算 C = A 即時推算 C = 1.618×A 實際低點

規則與比率檢查

    當下推算的低點（不偷看未來）

    每確認一個反彈高點 B，就用「從高點到當時的最低點」當 A 波，推算 C = A 與 C = 1.618×A（以幅度% 計）。

    推算日B 高點C = A誤差C = 1.618A誤差

    回測：當下推算低點有多準

    只看「低點出現之前」就發出的推算。每一點是一次推算；橫線是 ±5% 的命中區。

    方法

    1. 下跌段：收盤價轉折（zigzag）找出的高點，到「收復該高點」或「從低點翻倍」之前的最低收盤。門檻：台股、NDX、S&P 500 跌 15%，SOX 波動大用 25%。S&P 500 目前只跌 8%，所以「現在的位置」另外拿近一年高點計算。
    2. 數浪：在下跌段內部由粗到細找轉折（12% → 2%），窮舉所有符合規則的 A-B-C 與五波組合。五波必須遵守三條硬規則：第 2 波不超過起點、第 3 波不是最短、第 4 波不與第 1 波重疊。
    3. 符合度：A-B-C 看 C/A 有多接近 0.618 / 1 / 1.618 / 2.618，以及 B 波反彈是否落在 38.2%–78.6%；五波看第 3、5 波和第 1 波的比率，以及第 2、4 波的回檔深度。1.00 代表每一項都剛好卡在費波南希比率上。
    4. 回檔前波：跌幅除以「高點前三年最低點到高點」的漲幅。
    5. 即時推算：反彈高點以 zigzag 確認的那一天為準（門檻是下跌段門檻的 35%），只用到那天為止的收盤價，而且 B 波要反彈 A 波三成以上才算數。

    數浪本身就很主觀，同一段走勢常常有好幾種合理的數法；演算法挑出「最工整」的那一種，不代表當時的市場真的照這個結構走。這是技術結構的整理與回測，不是投資建議。資料來源：Yahoo Finance 日收盤價。
